# Projects

## Client-Side Model Inference & Validation Engine
A browser-based machine-learning inference and validation project demonstrating client-side model inference.

Features include real-time text classification, hyperparameter tuning, feature sensitivity analysis, confusion-matrix analysis, and model validation.

Technologies/concepts: ONNX Runtime, WebAssembly, machine learning, model validation, hyperparameter optimization.

## RAG-Powered Portfolio Assistant
A Retrieval-Augmented Generation assistant designed to answer questions about Sujoy's professional background, skills, education, experience, and projects.

Technologies/concepts: RAG, embeddings, vector search, conversational AI, FastAPI, Python.

## Live System Monitoring & MLOps Dashboard
An interactive MLOps monitoring dashboard demonstrating production-style machine-learning telemetry such as GPU/CPU utilization, model inference latency, P99 latency, data drift, and inference events.

## Career Dost
A student career-counseling web platform helping students explore career trajectories using aptitude, potential, and market needs.

Technologies: HTML5, CSS3, JavaScript, PHP, Bootstrap.

## AI-Powered Resume Builder & Formatter
An AI-oriented resume generation system that accepts profile information and produces professional resume formats.

## Student Performance Predictor
A supervised machine-learning project designed to predict a student's final academic score. The project includes feature processing, prediction, risk categorization, student profile analysis, and prediction reporting.

Technologies: Python, scikit-learn.

## Ultimate Banking Management
A Python banking-management application featuring customer account management, balance handling, CRUD operations, and object-oriented programming.

## Modular Student DBMS
A Python student-management system featuring student record management, CRUD operations, input validation, persistent data handling, and file I/O.

## Robotic Wireless RC Car

Technologies: Arduino, ESP32, C++.

## A* Search Autonomous Pathfinding Engine
